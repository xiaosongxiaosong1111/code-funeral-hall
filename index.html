01 / Agent Mission Control

它不是替代码办葬礼，
而是证明删除真的安全。

AI 都在教你怎么写代码，我们让 Agent 为删除代码负责。 Code Undertaker 调查依赖和 Git 证据，获得批准后受控删除；失败的回归测试会让旧代码“诈尸”，直到 Agent 完成最小修复。

Agent 尸检 → 用户批准 → Hook 裁决 → 诈尸 / 安息
现场：Kiro Hook 真实写入 回放：只看视觉效果
