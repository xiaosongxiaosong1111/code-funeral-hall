# 4 分钟参赛录屏脚本

目标时长：3 分 40 秒到 4 分 20 秒。你不需要临场发挥，按下面的画面和旁白执行即可。

## 录制前只检查这 6 件事

1. Kiro 和浏览器打开的是同一个刚刚克隆的项目根目录。
2. 浏览器打开 `http://127.0.0.1:4173`，不要直接双击 HTML。
3. `demo-src/legacy-ghost.mjs` 仍然存在并已被 Git 跟踪。
4. `npm test` 与 `npm run validate` 通过。
5. 页面右上角若显示“回放数据 · 非实时”，这是正常准备画面；正式证据必须在 Kiro 删除后变为“Kiro Hook · 实时”。
6. 建议录制 1920×1080；浏览器缩放到 110%–125%，以录屏里能直接看清导演台和测试状态为准。

## 剪辑规则

- Kiro 思考、命令等待和测试等待可以剪短，但不要打乱“删除 → Hook → 失败 → Bugfix → 通过”的顺序。
- 不要把“播放本地回放”当作真实 Hook 证据。
- 如果右上角始终没有变成“Kiro Hook · 实时”，停止录制并按 `KIRO-DEMO-GUIDE.md` 的 Hook 排查顺序检查。
- 不必逐行讲代码。评委只需要看懂问题、Kiro 能力、因果链和最终结果。
